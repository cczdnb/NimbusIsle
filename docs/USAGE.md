# 使用指南

云屿收在屏幕边缘。鼠标靠近就展开，左右箭头和底部圆点换页面，列表里面用滚轮看更多。托盘菜单可以打开设置、开关开机启动，或退出。

设置里关掉某个功能页后，页面会藏起来，对应的收信、同步和查询也会停。已经保存的数据还在，重新打开就恢复。

## 外观和常驻栏

**设置 → 常规 → 岛体外观** 里选皮肤和刘海／胶囊。六款皮肤是经典黑、奶油、毛玻璃·浅、毛玻璃·深、悬浮云、液态玻璃。液态玻璃抓不到身后画面，或这台机器比较吃力时，会自动改用深色毛玻璃。

**岛体显示** 里可以调大小、秒数、极简刘海、吉祥物、全屏隐藏、顶栏适配和 OLED 像素偏移。吉祥物是探出云朵的那张脸，平时停在收起的岛上。眨眼和换表情都是整张脸一帧一帧换。音乐响起时另播一套唱歌的动作。关掉之后岛上不再留它。拖动展开后的日期时间，可以在顶部、左侧、右侧之间换停靠位置。

## 桌宠

**设置 → 桌宠** 默认关闭。打开后，岛外面多一只跟着键盘和鼠标动的猫，岛上那张脸仍留着。需要系统里已经有 WebView2；没有的话，这一页会写出原因。

位置选「贴在岛左侧」时，猫和键盘离岛 8 像素，跟着岛走，从药丸旁边向下垂。这一侧放不下就换到另一侧。选「自由放置」后，按住身体拖动，松手记住位置。拖到屏幕边时，猫和键盘可以贴边，窗口里的空白可以探出屏幕。贴死在边角时，探出去的甩尾和生气符号会被屏幕切掉一截；旁边还有屏幕时，探出去的是一条透明窗口，点击会落到那块屏幕上。按住头是摸猫。点在猫和键盘以外的空白处，会落到下面的窗口。

大小默认 40%。六种毛色是奶牛、橘猫、虎斑、三花、白猫和蓝猫。键盘可以在 65% 和 104 之间换，104 会把窗口加宽、加高。隐私模式只区分左右手，不把具体按键交出去。可以分别开关摸头时的呼噜和睡觉时的呼噜，也可以设闲置多久趴下。「会不耐烦」打开时，打得太快、一下子按很多键、摸太久，或者把睡着的猫吵醒，它会生气，扬起尾巴连捶几下桌子，额头冒出怒纹。安静下来后自己消气。

锁定点击穿透后，整窗不接收鼠标。按住 Alt 可以临时拖动或摸猫。打开「全屏时隐藏」时，桌宠和岛一起藏起来。照片取色和 AI 接入还没接上。

收起时的常驻栏可以分别开关时间、电量、天气、CPU 和内存。CPU 和内存默认关闭，大约每秒在本机采样一次。排列顺序在「常驻排列」里拖动。

下班倒计时在 **设置 → 页面管理**。设上班时间和下班时间，收起的岛按下班时间倒计时，精确到秒，下面按小时分成白、黄、橙、红。最后一分钟岛会拉开，图下面是剩下的秒数。自动避让把岛收成细线时，这段通知仍会拉开。最后 5 秒铺满屏幕倒数，到 0 之后整屏黑 5 秒，点一下或按 Esc 就回到岛上，电脑不会关机。到点后倒计时收起。周六日可以不显示。倒计时和其它常驻项一起算进岛的宽度。整排顶到屏幕边时，先收起内存和 CPU；再放不下的额度图标会暂时让开，不会把程序退出。「倒计时专属表情」打开后，按上班、午休和下班这些时段换一套表情。听歌时仍播唱歌的动作。关掉则用平时的表情。

## 音乐和快捷键

音乐来自 Windows 媒体会话。播放器要提供歌名、进度这些信息，云屿才能显示和跳转。歌词对不上时，可以在音乐页点重试。字号、译文、对齐、动画、频谱和进度条在 **设置 → 音乐与歌词**。

「岛上歌词」打开后，收起的顶部岛体会把封面、歌词和控件并排显示。关掉时，播放中仍用原来的顶行，媒体条加在下面。极简刘海要打开这个开关，才会显示歌词。

全局快捷键出厂不绑定。在同一页填写组合键，例如 `Ctrl+Alt+P`。可绑定的是播放／暂停、上一首、下一首、快退 5 秒、快进 5 秒、唤出或隐藏。被别的软件占用的那一条会标成「未生效」，其余照常使用。

## 邮箱

在 **设置 → 邮件** 填写完整邮箱地址，选择服务商，再填授权码或 App 专用密码。不要把授权码发到聊天、Issue 或截图里。

| 邮箱 | 凭据在哪里生成 |
| --- | --- |
| QQ | 网页版右上角「设置」→「账号与安全」→「安全设置」→ 打开 IMAP 并生成授权码 |
| 163／126 | 网页版「设置」→「POP3/SMTP/IMAP」→ 打开 IMAP，按页面验证生成客户端授权密码 |
| 腾讯企业邮 | 网页版的客户端收发设置。管理员可能关掉 IMAP |
| iCloud | Apple 账号打开双重认证后，在账号安全页生成 App 专用密码 |
| Gmail | Google 账号打开两步验证后生成应用专用密码。单位账号可能被管理员关掉 |

设置页有对应说明和网页入口。Gmail 在有的网络里需要能访问 Google。云屿不改系统的网络设置。

Outlook、Hotmail、Live 和 Microsoft 365 需要 OAuth。填这类地址或已知的微软云 IMAP 主机时，测试和保存会停用。

连上后先读最近 20 封，运行期间列表最多留 60 封。新邮件优先用 IMAP IDLE，另外有定期补查。验证码卡片点一下复制。点进邮件可以读正文；「阅读全文」打开独立窗口。HTML 保留标题、列表、加粗、引用和表格。远程图片不自动加载。

列表可以筛「全部／未读」。打开后标为已读，也可以手动改回去。删除是移到当前模式的回收站，从列表右下角的垃圾桶进去，可以恢复。

「同步邮件操作到邮箱」默认关闭，只改云屿里的记录。打开后，之后的已读、删除和恢复会写回服务器。之前只在本机做过的操作不会补交。远程移动需要邮箱支持 IMAP MOVE。

## 日程

在 **设置 → 日程** 选择平台，填写 CalDAV 或对应的连接信息。只登录飞书、钉钉、企业微信的桌面客户端，不会自动把日历权限给云屿。

- 左侧月历选日期，右侧按时间列日程，全天的排在前面。
- 日期标题旁是农历、节气和常见节日。日程列表上方是当日宜忌。算不出来时显示「无」。这部分不联网。
- 大卡片是当前选中的日程。滚轮只滚下面的列表。
- 自动同步默认每 5 分钟一次。点右上角的更新时间可以马上刷新这个月。
- 提前提醒可选 5／15／30 分钟。全天安排出现在日历里，午夜不弹会议提醒。
- 普通邮件正文里的日期不会进日程。带日历附件的正式邀请会自动出现。邮件日程右侧的 × 用来忽略，详情里可以恢复。忽略只影响云屿，不删工作日历里的那一条。

本机新建和导入的 `.ics` 留在本机。远程日历是只读同步。同步失败时界面会留错误说明。退出、关机或睡眠期间不会继续提醒。

## 待办、专注、喝水和久坐

本机待办在待办页填写。提醒是可选项，用日期和时间选择器设置。

第三方待办在 **设置 → 待办与置物 → 第三方**。可选 Jira、Linear、GitHub Issues、Notion、飞书多维表格、Windows 待办或自建 JSON。令牌保存进 Windows 凭据管理器，不写进明文配置。Windows 待办用一次微软登录，定时同步时不再弹窗。到期、即将到期和未排期在待办页和第三方页里分开看。勾选完成时，Jira、Linear、GitHub、Notion 和 Windows 待办可以写回；飞书和自建 JSON 只读。

专注和休息要点开始，一个阶段结束后可以进入下一个。

健康页在「喝水」和「久坐」之间切换。两边各自有时长和提醒开关。提醒上点「知道了」后重新计时；久坐还可以点「起身了」。喝水页用「喝一口」记一次，记错了可以撤销。达到当日目标后停止喝水提醒。午休时段可以让两边都不弹。

## AI 额度

先登录对应的工具，再在 AI 额度设置里识别本机账号。多个账号可以改名、选颜色、决定是否常驻。

Codex、Claude、Kimi 的登录由各自的客户端管。Claude 桌面版只读本机历史和用量缓存；换账号后要等新记录出现。手动打开 Claude Code 本地采集时，云屿会写入采集脚本并设置状态栏；原来已有状态栏命令的，会保留。

Grok Bot、Gemini、豆包各有自己的连接入口。豆包可以「浏览器登录」，优先用系统默认的 Chrome 或 Edge，在独立窗口完成官网登录；也可以「从本机导入」。登录状态加密留在本机。

套餐和中转站用 API Key 或站点令牌。自定义查询脚本只访问你填的那个 HTTPS 接口。

## 会话

会话页列出本机正在跑、等你处理、报错停了和刚跑完的 Agent。点一行打开对应软件，并把它从岛上撤下。收起时有会话会在岛边显示这家软件的图标和数量，点它进入会话页。正在跑不弹提醒；等你处理、报错和刚跑完会提醒。

能读 Cursor、Claude、Codex、WorkBuddy、DeepSeek 和 Antigravity，只取状态，不把整段对话放进岛上。

**设置 → 会话** 里可以按软件关掉读取。刚跑完和报错停了的会话默认再留 10 分钟，可以改成 1 到 60 分钟。到时间，或者在岛上点开这一行，它才消失。在原来的软件里标成已读不算看过。

## 天气

**设置 → 天气** 里选择 Open-Meteo 或和风天气。Open-Meteo 不用密钥，可以自动定位或手填城市。和风需要控制台分配的专属 Host 和 API Key，城市要在和风里重新选，最多单独保存 5 个。两种来源的城市和缓存互不覆盖。

收起栏上的天气图标可以在「状态组件」里关掉，天气页仍可使用。

## 更新、卸载和数据目录

安装包是 `Yunyu-Setup-v版本号-x64.exe`。可以改安装文件夹，并勾选桌面快捷方式和开机自启。第一次安装默认有桌面快捷方式，不开机自启。升级时保留你上次的选择。程序在 `%LOCALAPPDATA%\Programs\Yunyu`，数据在 `%APPDATA%\Yunyu`。

提示云屿正在运行时，先从托盘退出，再重试。窗口没有应答、提示暂时无法打开时，在任务管理器的「详细信息」里结束 `yunyu.exe`，再打开一次。

在 Windows 的已安装应用里卸载，会去掉程序和快捷方式，数据目录还在。要清掉账号，先在云屿设置里移除对应连接，再卸载。只删配置文件的话，凭据管理器里的密码和令牌还在。

## 常见问题

**窗口没出现：** 看托盘里是不是已经有一个实例，是不是正处在全屏，以及有没有打开「全屏时隐藏」或用快捷键把岛藏起来了。托盘点一下可以把藏起来的岛放出来。

**邮箱登录失败：** 确认填的是授权码或 App 专用密码，IMAP 已经打开，账号没有被管理员限制。网易邮箱需要先发一条客户端标识，连不上时会提示服务器不接受。

**日程连上了但没有安排：** 手动同步当前月份，并确认授权的日历里确实有这些日程。反馈时保留错误文字，不要附密码。

**验证码没有马上出现：** 先看信是不是在收件箱。垃圾箱不读。云屿要在运行，邮箱连接也要是通的。

**快捷键没反应：** 看这一条是不是显示「未生效：已被占用」。换一个组合再试。

**图标或布局不对：** 反馈时写上 Windows 版本、缩放比例、显示器数量，并附截图。截图先遮住账号、验证码和私人日程。
