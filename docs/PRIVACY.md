# 隐私与安全

## 留在本机的数据

云屿默认把这些放在 `%APPDATA%\Yunyu`：

- 设置、待办、本机日程和提醒
- 饮水记录、久坐计时相关设置
- 置物架里的文件路径（只记路径，不复制文件）
- 剪贴板最近 30 条文字，以及你固定的条目
- 邮箱、日历、天气、额度的连接信息
- 忽略过的邮件日程标记
- 第三方待办的同步配置 `todo-sync.json`，以及本机记下的完成状态

环境变量 `YUNYU_DATA_DIR` 可以把整个目录改到别处。开发自己的副本时用它，以免碰到日常数据。

农历、节气、节日和宜忌在本机计算，不为此访问网络。CPU 和内存大约每秒采样一次，只显示在常驻栏上，不上传。全局快捷键的组合写在本机设置里，由 Windows 注册，不发给别的服务器。

会话页只读本机已有的 Agent 记录，用来显示标题和状态，不上传，也不把整段对话放进岛上。在原来的软件里把会话标成已读，云屿不会因此把它撤下，也不会把这个状态写回去。读取位置是：Cursor 的 `%APPDATA%\Cursor` 与用户目录下的 `.cursor`，Claude 的 `.claude`，Codex 的 `.codex`，WorkBuddy 的 `.workbuddy`，DeepSeek 的 `.dsh`，Antigravity 的 `.gemini\antigravity`。在 **设置 → 会话** 里关掉某一家后，不再读它。

## 凭据放在哪里

邮箱密码、日历密码、API Key，以及 Jira、Linear、GitHub、Notion、飞书、自建 JSON 的待办令牌，保存在 Windows 凭据管理器。待办这项的服务名是 `Yunyu.TodoSync`。

Gemini、豆包的网页会话，以及 WorkBuddy 的独立会话，用当前 Windows 用户的 DPAPI 加密。中转站的自定义查询脚本和其中的凭据同样用 DPAPI。

本机 AI 客户端的登录文件只读。云屿不改原客户端的配置，也不替它刷新登录。Claude 不使用登录令牌，也不请求 Claude 的额度接口。

整个数据目录、凭据、Cookie、授权码和登录 JSON 都不适合公开上传。

## 打开功能之后会访问哪里

邮件读取收件箱，用来显示正文、识别验证码和日历邀请。不读垃圾邮件文件夹。当前邮件留在内存里。默认的已读、删除和恢复只改云屿里的记录；打开「同步邮件操作到邮箱」后，这些操作才会发给 IMAP 服务器。网易邮箱在登录前会发送一条 IMAP ID，名称和版本是云屿当前的 `Yunyu` 与程序版本号，服务器据此允许继续登录。

工作日历按你填写的地址访问 CalDAV 或 Exchange ActiveSync。Windows 上使用系统的 TLS 和证书信任库，并校验证书有效期和服务器名称。自签证书需要先放进 Windows 的信任库。日历诊断只记服务类型、同步范围、错误类别和数量，不记服务器地址、凭据或日程正文。

第三方待办只连接你选中的那一个来源：Jira、Linear、GitHub、Notion、飞书、微软待办或你填写的 JSON 地址。请求带上对应令牌。失败时保留上一份列表。Jira、Linear、GitHub、Notion 和 Windows 待办在你勾选完成时可以写回；飞书和自建 JSON 只读取。

下班倒计时不联网。下班钟点在本机设置里。

天气有两个来源，同一时间只用你选中的那个。

- **Open-Meteo：** 手填城市时发送城市名；自动定位时先向 `https://ipwho.is/` 询问网络出口的大致城市和坐标，失败再试 `https://free.freeipapi.com/api/v1/json`，然后用坐标查天气。大约每 15 分钟一次。关掉天气模块后不再发起新的查询。
- **和风天气：** 只访问你填写的 `qweatherapi.com` 专属域名，用 HTTPS 和 `X-QW-Api-Key`。Key 不写入设置、日志、诊断包或天气缓存。实况大约每 60 分钟、预报大约每 6 小时，并且只查当前城市。本机每个自然月最多 5,000 次出站尝试，计数存不住时停止请求。

最近的天气快照在 `weather-cities.json`。连接诊断在 `diagnostics/weather-network.log`，只记阶段、域名、直连或代理、耗时和错误类别，不记 IP、坐标、城市参数或代理凭据。日志超过 256KB 就轮转，不会自动上传。

音乐播放以 Windows 媒体会话为准。兼容网易云、酷狗、汽水时，会只读它们的本机歌词缓存、播放日志或播放队列，用来补歌名、时长、歌词和封面。系统和本机都没有封面时，会用歌名和歌手向网易云搜索一张缩略图。不修改播放器，不读取音频，不提取播放器的登录信息。

AI 额度只在对应账号启用时请求该服务的额度接口，或读取本机缓存。自定义脚本只访问脚本里配置的 HTTPS 地址。Cursor 额度只读本机 `state.vscdb` 里的当前登录，用该令牌向 Cursor 自己的用量接口查询两池剩余；令牌不写入云屿配置，也不替 Cursor 续期。

微信、企业微信、飞书、钉钉的新消息提醒看任务栏闪动，不读取联系人或聊天正文。QQ 和系统通知需要你授予的 Windows 通知权限。打开「显示通知正文」后，正文会出现在岛上，屏幕共享时建议关掉。

## 更新和诊断

启动后会访问 GitHub 的公开发布接口。成功则 24 小时后再查，失败则 1 小时后重试。请求头里有云屿的版本号，不附带设置、邮箱或日程。选择「下载并安装」时，安装包下到 `%LOCALAPPDATA%\Yunyu\Updates`，核对大小和 SHA-256 后再替换程序。

诊断包要你自己点「设置 → 关于 → 收集诊断」，或在程序打不开时从开始菜单的「收集云屿诊断」生成。包在桌面上，由你决定要不要发出去。里面可能有播放器名称、歌名、窗口状态和功能开关。用户目录会从路径里隐去。它不会自动上传。

云屿没有统一的云端账号，也没有自己的邮件或日程服务器。你连接的那些服务，仍适用它们自己的隐私政策。

## 反馈安全问题

凭据泄露、把认证信息发到错误的站点、文件越界访问，请用仓库的私密漏洞报告，见 [SECURITY.md](../SECURITY.md)。界面问题可以开公开 Issue，先去掉账号、验证码、令牌和私人日程。
